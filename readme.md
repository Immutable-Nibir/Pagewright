# Pagewright

A free, offline-first drag-and-drop web page builder that runs entirely in your browser.

No accounts. No server. No install.  
Just open the page and start designing.

## Features

- 🖱 Drag, resize, align and layer elements
- 📝 Buttons, text, panels and images
- ✨ Animations (fade, slide, zoom, bounce, pulse, rotate)
- 🔗 Clickable links on buttons
- 🎨 Glass / solid styles + opacity
- 🌓 Multiple themes (Light, Dark, Paper, Space, Forest, Ember…)
- 📐 Smart guides + grid snapping
- 📱 Mobile-friendly layouts
- 💾 Autosave + project files (.json)
- 📤 Export a complete, self-contained HTML page
- 🔒 Everything stays on your device

## How to use

1. Open `index.html` in any modern browser
2. Use the tools on the left (or top) to add elements
3. Select an element to edit text, colors, size, animation, etc.
4. Click **Export HTML** when you’re done
